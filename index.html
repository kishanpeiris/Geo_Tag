Photo compression

Applies to this device only.
Compress photos before saving
Phone photos — especially HDR ones — are often 3–5MB or more. With this on, photos are resized and re-encoded to a smaller JPEG before the location is written in, which cuts file size substantially with very little visible quality loss. The location is always written in after compression, so it's never affected either way. Non-JPEG photos (PNG, HEIC, etc.) are automatically converted to JPEG so a location can be embedded at all — that happens whether this is on or off.

This is what gets prefilled when you click "Email details" after creating or resetting an account. Use {{greetingName}}, {{username}}, {{password}}, {{role}}, {{company}}, and {{loginUrl}} anywhere in the subject or body. {{greetingName}} resolves to the company name for a Trade company-admin account, otherwise the first name if one's on file, otherwise the username.
About the logos: browser email links (the kind this app uses to open a new message in Outlook) can't carry file attachments or images — that's a restriction of every mail client, not something this app can work around. The reliable way to get both logos to appear at the bottom of every invite is to set them up once as your default signature in Outlook (File > Options > Mail > Signatures, with "Automatically include my signature on new messages" turned on) — Outlook then adds that signature, editable or removable per email, to every new message this app opens for you, these invites included. I've included both logo image files alongside this download so you can drop them straight into a signature.
